# Changelog

## 1.0.0 — 2026-10-07

- First release: `y710-led get` and `y710-led set LOGO BOTTOM` with
  off/low/medium/high for the Y logo and the bottom strips.
- DMI model check (`--force` to skip), CPU 0 pinning, port 0xB2 only,
  firmware error reporting.
- Tested on IdeaCentre Y710 Cube-15ISH (90FL), BIOS O2DKT17A.
